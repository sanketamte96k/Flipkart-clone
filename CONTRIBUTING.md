# 🤝 Contributing to Flipkart Clone

First off, thank you for considering contributing to the **Flipkart Clone** project! It is open-source contributions that make the developer community such an amazing place to learn, inspire, and create.

---

## 📋 Code of Conduct

By participating in this project, you agree to abide by our standards:
- Be respectful and polite to all project contributors.
- Keep issue discussions constructive and focused on technical facts.
- Respect community diversity and maintain zero tolerance for harassment.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
Before creating a bug report, please check existing issues to avoid duplicates.
When creating a bug report, please include:
- A clear, descriptive title.
- Steps to reproduce the bug.
- Expected vs. actual behavior.
- Environment details (OS, Python version, Browser).

### 2. Proposing Features
Feature requests are welcome! Please open an issue with:
- Summary of the proposed feature.
- Problem it solves or user value it provides.
- Technical considerations or proposed API design.

### 3. Pull Request Guidelines
1. **Fork the Repository**:
   ```bash
   git clone https://github.com/your-username/Flipkart-clone.git
   cd Flipkart-clone
   ```
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Make Your Changes**:
   - Follow existing code formatting conventions.
   - Do not break existing API endpoints or database contracts.
4. **Run Automated Tests**:
   ```bash
   python tests/run_tests.py
   ```
   Ensure all tests pass with 0 errors.
5. **Commit & Push**:
   ```bash
   git commit -m "Add amazing feature"
   git push origin feature/amazing-feature
   ```
6. **Open a Pull Request**: Submit a PR to the `main` branch.

---

## 🎨 Style Guidelines

- **Python**: Follow PEP 8 guidelines. Use 4 spaces per indentation level.
- **JavaScript**: Use modern ES6+ syntax (`async/await`, `const/let`, arrow functions).
- **CSS**: Use CSS custom properties defined in `style.css`.
- **HTML**: Maintain standard semantic HTML5 element structure and include `aria-label` accessibility attributes.

Thank you for building great software with us!
